The math your attention heads run on.

Four operations — dot product, matrix multiply, softmax, layer norm — are enough to describe every computation inside a Transformer. If you can picture these mechanically, the rest of the roadmap unfolds.

You don't need a linear-algebra degree to understand LLMs. You need to be fluent — mechanically, at the level of moving numbers around — in four operations. This chapter walks each one with a visual you can poke.

Vectors lists of numbers with a direction

A vector is a list of numbers. In ML a token embedding is a vector of length $d$ (often 768 or 4096); a batch of embeddings is a matrix $X \in \mathbb{R}^{N \times d}$, where $N$ is the number of tokens.

Geometrically, each vector is a point (or arrow) in a high-dimensional space. We can't draw 768 dimensions, but 2D intuitions carry over: closer vectors mean more similar meanings.

Dot product similarity in one number

// dot product of two vectors
$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{d} a_i b_i = \|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta$$

Multiply corresponding entries, sum them. The result is a single scalar that is:

  • Large and positive when the vectors point the same way — high similarity.
  • Zero when orthogonal — no overlap.
  • Negative when they point apart — anti-similarity.

Every attention score in a Transformer is a dot product between a query vector and a key vector. Every embedding similarity in a RAG system is a dot product. Every cosine similarity you've seen is a dot product, divided.

Matrix multiplication many dot products at once

A matrix multiply $C = AB$ is a grid of dot products. Each entry $C_{ij}$ is the dot product of row $i$ of $A$ with column $j$ of $B$. For shapes $A \in \mathbb{R}^{m \times k}$ and $B \in \mathbb{R}^{k \times n}$, the result is $m \times n$.

// entry-wise definition
$$C_{ij} = \sum_{p=1}^{k} A_{ip} B_{pj}$$

Every learned transformation in a Transformer is a matmul: token × $W_Q$ to get queries, token × $W_K$ to get keys, attention × value to mix information, hidden × $W_{out}$ to project back. When GPU engineers talk about "compute", they mean these matmuls.

Demo · Matrix multiply, visuallylive

Hover a cell in the result to see which row · column combined to make it.

// FLOPs, intuitively
A matmul of $(m \times k) \cdot (k \times n)$ costs $2 \cdot m \cdot k \cdot n$ floating-point operations. For GPT-3's attention at context 2048, $d = 12288$, $h = 96$, that's hundreds of billions of FLOPs per token. This is why every page after this one obsesses about memory bandwidth.

Softmax turning scores into probabilities

// softmax — normalize a vector into a probability distribution
$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$$

Softmax takes a vector of arbitrary real numbers and returns a vector of non-negative numbers that sum to 1. It exaggerates differences — a small gap in the input becomes a big gap in the output. This is why attention weights are so sharp: the biggest score dominates.

Layer normalization keeping activations in range

// layer norm along the last axis
$$\text{LN}(x) = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

For each vector in the batch: subtract the mean, divide by the standard deviation, then scale and shift by learned parameters $\gamma, \beta$. The effect: every vector has mean 0 and variance 1 before the learned affine.

Without layer norm, activations drift wildly across depth — some layers produce tiny outputs, some explode. The result is that gradients either vanish or detonate. Layer norm is the thing that makes stacking 100+ Transformer blocks feasible.

Putting it all together one attention head as pure math

Every ingredient so far, assembled as one attention head:

$$\text{Attention}(X) = \text{softmax}\!\left(\frac{(XW_Q)(XW_K)^{\top}}{\sqrt{d_k}}\right)(XW_V)$$
  1. $XW_Q, XW_K, XW_V$ — three matmuls.
  2. $QK^{\top}$ — one more matmul → an $N \times N$ score matrix.
  3. Divide by $\sqrt{d_k}$ — scalar divide.
  4. Softmax each row — row-wise normalization.
  5. Multiply by $V$ — one final matmul.

That is the full story. Every optimization you'll read about next — FlashAttention, PagedAttention, quantization — is about doing these same five steps faster, cheaper, or with less memory.

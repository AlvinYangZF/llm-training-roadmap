Many queries, few keys.

If multiple query heads can share the same K/V — and the math says they can — the cache shrinks proportionally. MQA collapses K/V to one head; GQA to a small group. Llama-2-70B uses GQA-8 for a reason.

The cache size formula has a hidden lever. 2 × L × N × h_kv × d — note h_kv, not h_q. Decouple them and you can keep all the query heads while collapsing the K/V side.

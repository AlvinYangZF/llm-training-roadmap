BM25 + dense + rerank — the boring default that wins.

Run lexical and semantic retrieval in parallel. Fuse with Reciprocal Rank Fusion. Rerank the top-50 with a cross-encoder. Three steps, one pipeline, near state-of-the-art on every public benchmark.

Retrieve · fuse · rerank

No clever tricks. Just admit BM25 and dense retrieval each catch failures the other misses, fuse their results with a robust rank-based formula, then let a strong but slow cross-encoder fix the top.

The pipeline

Stage 01 · Retrieve

Two retrievers · in parallel

BM25 over inverted index → top-100
Dense retriever (e.g. e5) → top-100

// out · 200 candidates · < 20 ms
Stage 02 · Fuse

Reciprocal Rank Fusion

Combine ranks not scores · doc score = Σ 1 / (k + rank). k=60 by convention. No score calibration needed.

// out · top-50 · < 1 ms
Stage 03 · Rerank

Cross-encoder · top-50 → top-k

Score (query, doc) jointly with a small BERT. Slow per pair, but only 50 pairs. Big quality lift.

// out · final top-k · ~60 ms

RRF · the formula

$$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + \text{rank}_r(d)}$$
// R = set of retrievers · k = constant (60) · rank starts at 1 · doc absent → contribution 0

Why ranks not scores: BM25 returns log-IDF sums (range 0–30+); dense returns cosine similarities (range -1–1). Calibrating across them is fragile. Ranks are unitless and bounded.

Cross-encoder · the rerank step

A bi-encoder embeds query and doc independently — fast but information-poor. A cross-encoder concatenates query and doc, runs them through a single Transformer, outputs a score. Quality is dramatically higher; cost is one forward pass per pair.

Run only on the top-50 candidates from RRF. At ~5 ms per pair on a small (e.g. ms-marco-MiniLM-L-12-v2) model, that\'s 60 ms total — usually the dominant latency in the pipeline.

SPLADE · learned sparse

SPLADE keeps lexical interpretability but learns the term weights with a Transformer. Output: a sparse vector of vocabulary-sized term weights. Index it like BM25 (inverted), retrieve like BM25, but each term\'s contribution is contextual. Often replaces BM25 in the pipeline\'s lexical leg.

Don\'t retrieve when you already know.

Self-RAG, CRAG, FLARE — three flavours of the same idea. Stop treating retrieval as a fixed pipeline; let the model decide when, what, and how much to fetch. Latency drops, accuracy holds.

Vanilla RAG retrieves once, blindly, no matter the query. Adaptive RAG asks the model itself: do I need help here? Often the answer is no — and skipping retrieval is faster and more accurate.

The retrieval-cost problem

Every retrieval step is 50–200 ms (vector lookup) + 1–2k tokens of context. For trivial queries — "what year was Python released?" — the model already knows. Forcing retrieval adds latency, dilutes the prompt, and sometimes injects bad context that hurts accuracy.

Self-RAG · reflection tokens

Train the model to emit [Retrieve], [Relevant], [Supported], [Useful] as part of its output stream. At inference, a controller reads these tokens and conditionally fetches passages, re-ranks them, or skips ahead.

Demo · Reflection-token streamtrace
User asks: "Who wrote The Great Gatsby?"
[Retrieve=No] F. Scott Fitzgerald wrote The Great Gatsby in 1925. [Useful=Yes]

User asks: "What did Anthropic ship in March 2025?"
[Retrieve=Yes] → search · top-3 → [Relevant=Yes] Anthropic released Claude 3.7 Sonnet in March 2025 [Supported=Fully] with extended thinking…

CRAG · grade and correct

CRAG retrieves first, then asks a lightweight evaluator: are these passages actually useful? Three branches: Correct (use as-is), Ambiguous (refine + websearch), Incorrect (discard, do websearch). The evaluator is a small T5 — not the main LLM — so the overhead is bounded.

01 retrieve
Top-k from local index — same as vanilla RAG.
02 grade
T5-large evaluator scores each passage. Threshold splits into 3 buckets.
03 branch
Correct → refine and use · Ambiguous → refine + web · Incorrect → discard, web only.
04 generate
LLM gets the refined context. Refinement strips boilerplate, keeps strips of relevant text.

FLARE · trigger on uncertainty

FLARE generates a draft sentence first. If any token has probability below a threshold (default 0.5), the low-confidence span becomes the next query. Retrieve, regenerate that sentence, continue. The result: retrieval happens mid-generation, only at the moments it\'s actually needed.

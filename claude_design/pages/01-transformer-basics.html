Attention is all you need.

The Transformer replaced recurrence with a single mechanism — scaled dot-product attention — that lets every token in a sequence look at every other token in parallel. Eight years later it still runs every model you've heard of.

In June 2017, a Google team published a paper titled Attention Is All You Need. It ran 15 pages. It contained one diagram — the now-ubiquitous stack of boxes — and a single formula that would, within five years, dominate every subfield of machine learning. This page unpacks that formula, mechanically, one piece at a time.

The problem with recurrence why 2017 needed something new

Before Transformers, language models used recurrent neural networks — they processed tokens one at a time, passing a hidden state forward. This had two fatal flaws for scale:

  • Sequential. To compute token N, you needed tokens 1 through N−1. No GPU parallelism within a sequence.
  • Forgetful. Information from position 1 had to survive 500 hops of matrix multiplication to reach position 500. In practice, it didn't.

The Transformer proposes a radical alternative: every position attends to every other position directly, in a single matrix multiplication. No recurrence, no convolution, no sequential bottleneck.

Tokens become vectors the embedding step

Before any attention happens, each token is mapped to a vector of dimension $d_{model}$ — typically 512, 768, or 4096. A vocabulary of size $V$ becomes a lookup table $E \in \mathbb{R}^{V \times d_{model}}$. Token 1337 is just row 1337.

Positional information is added next — either sinusoidal (original paper) or learned (GPT-2) or rotary (LLaMA). Without it, the Transformer would be permutation-invariant: "dog bites man" and "man bites dog" would produce identical outputs.

Query · Key · Value three projections, one mechanism

Here is the central idea: for each token, we compute three different vectors by multiplying the embedding by three learned matrices. These are, by convention, called Query, Key, and Value.

Query (Q)

$Q = XW_Q$
"What am I looking for?" — one vector per token, posted as a question to every other token.

Key (K)

$K = XW_K$
"What do I have?" — each token advertises its content through a key. Queries are matched against keys.

Value (V)

$V = XW_V$
"What do I contribute?" — the actual information passed along once attention weights are determined.

The analogy that clicks for most people: a Transformer layer is a differentiable dictionary lookup. Each token poses a query, every other token offers a key; the dot product query · key measures how well they match; the softmax turns matches into probabilities; values are weighted and summed.

Scaled dot-product attention the single formula that runs the world

// Attention formula — from Vaswani et al. 2017
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^{\top}}{\sqrt{d_k}}\right) V$$

Read this left to right:

  1. $QK^{\top}$ — a matrix of dot products, one per (query, key) pair. Shape $N \times N$ where $N$ is sequence length.
  2. Divide by $\sqrt{d_k}$ — a scaling trick. Without it, large dot products push softmax into regions where gradients vanish.
  3. Softmax over each row — turn raw scores into probabilities that sum to 1.
  4. Multiply by $V$ — each output token is a weighted sum of value vectors.
// intuition
The √d_k scaling is not cosmetic. For $d_k = 64$, unscaled dot products have standard deviation 8. Softmax on values of that magnitude is effectively a one-hot — gradients die. Divide by 8 and you're back to a well-behaved distribution.

Multi-head attention many conversations at once

One attention mechanism can only learn one kind of relationship. So Transformers run $h$ of them in parallel — typically $h = 8$ or $h = 12$ — each with its own $W_Q$, $W_K$, $W_V$. Outputs are concatenated and projected:

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W_O$$

Empirically, different heads learn different roles — some track syntax, some track coreference ("it" → "the dog"), some track nothing interpretable. This redundancy is a feature: if one head breaks, the rest compensate.

The full block how the pieces stack

A Transformer block is attention followed by a feed-forward network, each wrapped in a residual connection and layer normalization. A model is $L$ blocks stacked deep — $L=6$ in the original paper, $L=96$ in GPT-3, $L=126$ in Llama 3.1 405B.

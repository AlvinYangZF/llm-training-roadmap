The model learns by being wrong.

Cross-entropy measures how surprised the model is by the right answer. Backprop pushes weights to make it less surprised next time. Repeat ~10¹³ times.

A language model is just a function from context to probability distribution over the vocabulary. Training is the process of nudging that function to put more mass on the tokens that actually came next.

Cross-entropy · the loss

For each predicted token, compute the negative log-probability the model assigned to the true next token. Sum across the sequence, average across the batch. That\'s it.

L = −∑ log p(xt | x<t)
// average over tokens · perplexity = exp(L)

If the model assigns 0.5 to the right token, the loss is 0.69. If it assigns 0.99, the loss is 0.01. If it assigns 0.001, the loss is 6.9. The log makes high-confidence wrong answers very expensive.

Gradient descent · the move

Backprop computes ∂L/∂w for every parameter. Adam adapts the step per parameter using running estimates of the gradient mean and variance. Update: w ← w − η · m̂/(√v̂ + ε).

Schedules · the discipline

A constant LR will overshoot at the start (random init) and undershoot at the end (near a minimum). Schedules fix this. Three you\'ll see in every paper:

Linear · simplest

Warmup → linear decay

Warm up over the first few % of steps to avoid early divergence, then decay linearly to zero.

Cosine · 2020s default

Smooth half-cycle

Same warmup, then a smooth cosine decay. Why cosine? Empirically, slightly better. Mostly tradition.

WSD · 2024 trend

Warmup, stable, decay

Constant LR for most of training, late-stage decay. Cleaner ablations · cheap to extend a run.

What goes wrong

  • Loss spikes → bad batch, gradient explosion. Clip gradients to norm 1.0. Skip-and-continue is fine.
  • Loss plateau → LR too small, or model is overfit on something narrow. Add data variety.
  • Loss diverges → LR too high, mixed-precision underflow. Lower LR, switch to bf16, longer warmup.
  • Train-eval gap → overfitting. Add dropout, data, or stop training.
